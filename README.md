# Junyi Li — Personal Website

Responsive multi-page academic portfolio for **Junyi Li**, PhD Candidate.

## Pages

- `index.html` — Home and About
- `research.html` — Journal articles and conference proceedings with filter tabs
- `projects.html` — Data/model, writing/report, and architecture/design projects with filter tabs

## Preview locally

Open the folder in VS Code and run `index.html` using the Live Server extension. Navigation between all three pages works locally.

## Customize

Edit the placeholder content in each HTML file. Add your CV as `assets/Junyi-Li-CV.pdf`, then update your email, Google Scholar, LinkedIn, PDF, DOI, and GitHub links.

## Publish

Upload all files to a repository named `ljyyyy120.github.io`, then enable GitHub Pages from the `main` branch and root folder.
